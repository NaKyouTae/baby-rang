# 방 꾸미기 아이템 만들기 (ChatGPT 시트 → 개별 PNG)

한 번 요청으로 아이템 여러 개를 한 장(시트)에 그리게 하고, 스크립트로 잘라 개별 PNG 로 저장한다.

## 순서

1. 아래 **시트 프롬프트** 하나를 ChatGPT 에 그대로 붙여 넣는다(공통 문구가 이미 들어 있다).
2. 받은 이미지를 내려받는다.
3. 자른다.
   ```bash
   node scripts/slice-sprites.mjs ~/Downloads/받은이미지.png <시트 이름>
   ```
4. `scripts/sprite-out/<시트 이름>/` 에 아이템별 PNG 와 확인용 `_preview.png` 가 생긴다.
   - 파일 크기가 곧 방에서의 크기다(16px = 1칸). 어드민 칸 수를 파일 크기 ÷ 16 으로 넣는다.
   - 벽지·바닥재는 `_preview.png` 에 3×3 으로 이어 붙여 보여 준다. 이음매가 보이면 다시 받는다.
5. 개수가 안 맞으면 저장하지 않고 `_boxes.png` 에 찾은 상자를 표시한다.
   보통 아이템끼리 붙었거나 한 아이템이 둘로 떨어진 경우다. ChatGPT 에 "아이템 간격을 더 넓게" 라고 다시 요청한다.

시트 이름과 아이템 순서·크기는 이 폴더의 `<시트 이름>.json` 에 있다. 아이템을 바꾸면 json 도 같이 고친다.

## 받은 그림이 이상할 때 ChatGPT 에 덧붙일 말

- 사선으로 나옴 → `아이소메트릭이 아니라 정면 직교 시점으로. 모든 모서리는 수평·수직.`
- 배경이 체크무늬 → `체크무늬가 아니라 실제 투명 배경 PNG 로.`
- 순서가 섞임 → `번호 순서대로 왼쪽 위부터 가로로.`
- 번호·글자가 들어감 → `번호·글자·이름표 없이 아이템만.`
- 지금 홈 화면 스크린샷을 같이 올리고 `이 화면과 같은 시점·그림체로` 라고 하면 가장 잘 맞는다.

## 시트 1. 벽지·바닥재 — `tiles` (9개, 16×16 반복 무늬)

```
아기방 꾸미기 게임의 벽지·바닥재 무늬 견본 9개를 픽셀아트로 한 장에 그려줘.

[배치]
- 1536×1024 가로 이미지, 완전 투명 배경 PNG(체크무늬로 투명을 흉내 내지 말 것).
- 정사각형 견본 9개를 왼쪽 위부터 가로 3개씩 3줄. 번호 순서를 지킨다.
- 견본끼리 넉넉히 떨어뜨린다(견본 폭의 절반 이상). 번호·글자·테두리 칸 없이 견본만.
- 각 견본은 16×16 픽셀 무늬. 픽셀 하나하나가 같은 크기의 정사각 블록으로 보이게 크게 확대해서, 안티앨리어싱·블러 없음.
- 견본 안은 빈틈없이 색으로 꽉 채운다(투명한 곳 없음).

[반복 조건 — 가장 중요]
- 이 견본 하나를 상하좌우로 끝없이 이어 붙여 벽·바닥 전체를 채운다.
- 오른쪽 끝이 왼쪽 끝과, 아래 끝이 위 끝과 이음매 없이 이어져야 한다(seamless tile).
- 작은 무늬(구름·별·하트·잎)는 견본 가장자리에 걸리지 않게 안쪽에 둔다.
- 줄무늬·체크는 견본 가장자리에서 정확히 반복 주기가 끝나게.

[색]
- 위에 글자가 올라가는 배경이라 밝고 채도 낮은 파스텔. 무늬는 바탕보다 한 단계만 진하게.

[견본 9개]
1. 벽지 — 민트와 흰색 세로 줄무늬(줄 폭 4픽셀씩)
2. 벽지 — 연하늘 바탕에 작은 흰 구름 하나(6×4픽셀 정도)
3. 벽지 — 연노랑 바탕에 작은 별 하나와 초승달 하나(각 3~4픽셀)
4. 벽지 — 연분홍 바탕에 작은 하트 하나와 물방울 점 하나
5. 벽지 — 연노랑과 흰색 체크(칸 8픽셀)
6. 벽지 — 연초록 바탕에 작은 잎사귀 두 개
7. 바닥재 — 밝은 원목 마루. 가로 판자 두 줄, 판자 이음매가 엇갈림, 나무색 #EBC79B / #D6A878
8. 바닥재 — 파스텔 퍼즐매트. 8×8 칸 4개가 각각 다른 파스텔 색, 칸 경계에 퍼즐 이음 모양
9. 바닥재 — 연한 베이지 카펫, 작은 점 결 무늬
```
