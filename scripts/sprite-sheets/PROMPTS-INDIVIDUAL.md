# 방 꾸미기 아이템 — 한 번에 요청해서 개별 이미지로 받기 (ChatGPT)

프롬프트 하나를 붙여 넣으면 ChatGPT 가 아이템마다 이미지를 **따로** 연달아 만든다.

## 파일 이름을 아이템 이름으로 맞추기

ChatGPT 는 내려받는 파일 이름을 정할 수 없다(프롬프트로도 안 된다). 대신 **번호 순서대로 내려받고** 스크립트로 이름을 바꾼다.

1. 이미지마다 위에 적힌 번호 순서(1 → 2 → 3 …)대로 하나씩 내려받는다. 순서가 곧 이름이다.
2. 다 받았으면 바꿀 목록을 먼저 본다.
   ```bash
   node scripts/rename-sprites.mjs rugs
   ```
3. 순서가 맞으면 실제로 바꾼다.
   ```bash
   node scripts/rename-sprites.mjs rugs --apply
   ```
   `~/Downloads` 에서 가장 최근에 받은 이미지를 받은 순서대로 `rug-round.png`, `rug-cloud.png` … 로 바꾼다.
   다른 폴더면 시트 이름 뒤에 폴더 경로를 넣는다. 같은 이름 파일이 이미 있으면 덮어쓰지 않고 멈춘다.

시트 이름: `tiles` · `rugs` · `wall-decor` · `floor-decor` · `windows` · `furniture-a` · `furniture-b` (각 프롬프트 제목 옆에 적어 둠)

## 진행 팁

- ChatGPT 는 한 번에 몇 장 만들고 멈추는 경우가 많다. 멈추면 `계속` 이라고 보내면 다음 번호부터 이어서 만든다.
- 그림체가 흔들리면 `1번과 같은 그림체·같은 픽셀 크기로 다시` 라고 보낸다. 다시 만든 이미지는 원래 번호 자리 순서에 맞춰 내려받는다.
- 다른 이미지를 중간에 내려받으면 순서가 밀린다. 목록 확인(2번)에서 이상하면 그 파일을 옮긴 뒤 다시 실행한다.
- 한 장에 모아 받은 뒤 스크립트로 자르는 방법은 [README.md](README.md) 를 본다.

## 벽지·바닥재 — 9개, 16×16 반복 무늬 · `tiles`

```
아기방 꾸미기 게임의 벽지·바닥재 무늬 견본 9개를 픽셀아트로 만들어줘. 아이템마다 이미지를 따로 만든다.

[진행 방식]
- 이미지 한 장에 아이템 하나만. 여러 개를 한 장에 모으지 말 것.
- 아래 목록 1번부터 순서대로, 한 장 만들 때마다 질문하지 말고 바로 다음 번호를 이어서 만든다.
- 이미지마다 바로 위에 "번호. 파일이름" 한 줄을 적는다(예: 1. wallpaper-mint-stripe.png). 나는 이 번호 순서대로 내려받아 그 파일이름으로 저장한다. 이미지 안에는 번호·글자를 넣지 않는다.
- 번호를 건너뛰거나 순서를 바꾸지 않는다. 다시 그려 달라고 하면 같은 번호·같은 파일이름으로 다시 만든다.
- 한 번에 다 못 만들면 멈춘 번호를 알려 주고, 내가 "계속"이라고 하면 그다음 번호부터 이어서 만든다.
- 모든 이미지는 같은 그림체, 같은 픽셀 크기(픽셀 블록 크기 동일), 같은 색감으로 맞춘다.
- 괄호 안은 아이템의 실제 픽셀 크기(가로×세로). 픽셀 하나하나가 같은 크기의 정사각 블록으로 보이게 크게 확대하고, 안티앨리어싱·블러 없음.
- 이미지는 정사각형(1024×1024). 견본 하나가 이미지 전체를 빈틈없이 채운다(투명한 곳 없음, 여백 없음).

[반복 조건 — 가장 중요]
- 이 견본 하나를 상하좌우로 끝없이 이어 붙여 벽·바닥 전체를 채운다.
- 오른쪽 끝이 왼쪽 끝과, 아래 끝이 위 끝과 이음매 없이 이어져야 한다(seamless tile).
- 작은 무늬(구름·별·하트·잎)는 견본 가장자리에 걸리지 않게 안쪽에 둔다.
- 줄무늬·체크는 견본 가장자리에서 정확히 반복 주기가 끝나게.

[색]
- 위에 글자가 올라가는 배경이라 밝고 채도 낮은 파스텔. 무늬는 바탕보다 한 단계만 진하게.

[견본 9개]
1. [wallpaper-mint-stripe.png] 벽지 — 민트와 흰색 세로 줄무늬(줄 폭 4픽셀씩)
2. [wallpaper-cloud.png] 벽지 — 연하늘 바탕에 작은 흰 구름 하나(6×4픽셀 정도)
3. [wallpaper-star-moon.png] 벽지 — 연노랑 바탕에 작은 별 하나와 초승달 하나(각 3~4픽셀)
4. [wallpaper-heart-dot.png] 벽지 — 연분홍 바탕에 작은 하트 하나와 물방울 점 하나
5. [wallpaper-yellow-check.png] 벽지 — 연노랑과 흰색 체크(칸 8픽셀)
6. [wallpaper-leaf.png] 벽지 — 연초록 바탕에 작은 잎사귀 두 개
7. [flooring-light-wood.png] 바닥재 — 밝은 원목 마루. 가로 판자 두 줄, 판자 이음매가 엇갈림, 나무색 #EBC79B / #D6A878
8. [flooring-puzzle-mat.png] 바닥재 — 파스텔 퍼즐매트. 8×8 칸 4개가 각각 다른 파스텔 색, 칸 경계에 퍼즐 이음 모양
9. [flooring-dot-carpet.png] 바닥재 — 연한 베이지 카펫, 작은 점 결 무늬
```
